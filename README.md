# Meu Treino (PWA)
Vite + React + TypeScript + Dexie. Dados 100% locais (IndexedDB).

    npm install
    npm run dev       # desenvolvimento
    npm run build     # gera dist/
    npm run preview   # testa o build (PWA/offline)

A pasta `android-legado/` guarda a versão Android (Etapa 1) e não é publicada na Vercel.
